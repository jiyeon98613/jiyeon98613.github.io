담당 범위와 협업

NHIS 프로젝트에서는 청구 업무의 요구사항과 예외를 정리하고 DB 영역을 주로 담당했습니다. SQL과 Python 구현에는 AI 코딩 도구를 적극 활용했습니다. 제가 결정한 조건과 실제 확인한 결과를 중심으로 작업을 설명합니다.

관리자 콘솔은 협업 결과물입니다. 화면을 함께 검토하고, 제가 맡은 데이터 모델·조회·변경 계약을 프런트엔드와 조율했습니다.

데이터가 정확하게 저장되는 것에 더해, 문제가 생겼을 때 원인과 처리 근거를 확인하고 복구할 수 있는 운영을 배우고자 합니다.
